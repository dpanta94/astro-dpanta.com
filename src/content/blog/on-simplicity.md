There's a certain discipline in keeping things simple. Not the laziness of leaving things undone, but the restraint of knowing what to leave out.

Good software, like good writing, is mostly editing.

```javascript
// Sometimes the simplest solution is the best one
function greet(name) {
  return `Hello, ${name}!`;
}

const message = greet("world");
console.log(message);
```

Less is more.
